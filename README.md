# WealthDrop

Income-fair gamified savings for GXBank. We read transaction behavior for the patterns banks can't see, generate a unique living creature for every user, and let friends battle on improvement velocity — never on income.

## What's here
- `/frontend` — Next.js app with creature renderer, constellation viz, battle UI
- `/ml-pipeline` — Python ML pipeline (n-gram pattern mining, UMAP embedding, 5-axis stat computation)
- `/docs` — Architecture, demo script, pitch Q&A
